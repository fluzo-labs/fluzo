# Security Reporting

There is no released Fluzo runtime yet. The planned permission and confinement
contracts are not a claim of proven sandboxing or completed security testing.

Use [private vulnerability reporting](https://github.com/fluzo-labs/fluzo/security/advisories/new)
for vulnerabilities. Do not open a public issue containing exploit details,
credentials, personal data or private source code. Include affected revisions,
a minimal synthetic reproduction and impact.

If private reporting is unavailable, do not publish sensitive details; report
the unavailable channel through GitHub Support. Documentation-specific issues
can use the [documentation repository's private reporting form](https://github.com/fluzo-labs/fluzo-docs/security/advisories/new).
